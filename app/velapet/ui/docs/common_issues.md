# VelaPet 组员三常见问题

## 图片加载失败

现象：形象页或主页无法显示生成后的表宠图片。

处理：

1. 确认组员四同步的路径是否存在。
2. 确认图片格式是否被当前 LVGL 图片解码器支持。
3. 调用 `velapet_ui_pet_image_set_state(3, path)` 显示失败状态。
4. 使用默认表宠形象兜底，避免页面空白。

## 按钮无响应

现象：点击任务、AI、皮肤等按钮没有页面跳转。

处理：

1. 确认触摸驱动已注册到 LVGL。
2. 确认按钮对象没有被其他对象覆盖。
3. 确认事件类型为 `LV_EVENT_CLICKED`。
4. 真机上检查按钮尺寸，过小会影响触摸命中。

## 经验条不刷新

现象：领奖或签到后主页经验条仍是旧值。

处理：

1. 领奖成功后调用 `velapet_ui_refresh_all()` 或返回主页触发刷新。
2. 确认 `vela_pet_claim_task()` 已更新 `PetProfile.exp`。
3. 确认 `exp_to_next` 不为 0。

## 任务状态不正确

现象：已完成任务仍显示进行中，或已领奖任务还能再次领取。

处理：

1. 检查 `Task.status` 是否使用统一枚举值。
2. `TASK_STATUS_COMPLETED` 才显示 Claim。
3. `TASK_STATUS_REWARD_CLAIMED` 不应再次绑定领奖事件。

## AI 回复过长

现象：AI 回复在手表小屏显示不完整。

处理：

1. 组员四返回文本建议控制在 50 字以内。
2. 前端使用自动换行和滚动容器。
3. 网络失败时使用本地短句兜底。
