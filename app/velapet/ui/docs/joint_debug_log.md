## 演示流程

1. 进入 VelaPet 主页，展示表宠名称、等级、经验条、今日任务进度。
2. 点击 Tasks，查看任务卡片，完成任务后领取 EXP。
3. 点击 Check in，显示连续签到天数。
4. 返回主页进入 AI，点击快捷按钮，显示表宠鼓励语。
5. 返回主页进入 Pet，展示默认/生成中/加载成功/失败状态。
6. 返回主页进入 Skin，展示已解锁与未解锁皮肤，已解锁皮肤可切换。
